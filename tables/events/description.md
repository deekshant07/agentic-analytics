# User Events Log

This table stores user interaction events within a mobile application, primarily focused on onboarding and transaction activities.

### Aadhaar Number Entered
`aadhaar_number_entered`
This event captures when a user enters their Aadhaar number during the onboarding process.

### Aadhaar OTP Requested
`aadhaar_otp_requested`
This event indicates that the user has requested an OTP for Aadhaar verification.

### Aadhaar OTP Verified
`aadhaar_otp_verified`
This event signifies that the user has successfully verified their Aadhaar OTP.

### App Install
`app_install`
This event captures when the user installs the application.

### App Opened
`app_opened`
This event captures when the user opens the application.

### Bureau Pull Completed
`bureau_pull_completed`
This event indicates that the bureau pull process has been successfully completed.

### Bureau Pull Initiated
`bureau_pull_initiated`
This event captures when the bureau pull process is initiated.

### Date of Birth Entered
`dob_entered`
This event captures when the user enters their date of birth during onboarding.

### Email Entered
`email_entered`
This event captures when the user enters their email address during onboarding.

### Home Screen Viewed
`home_screen_viewed`
This event captures when the user views the home screen of the app.

### Mobile Number Entered
`mobile_number_entered`
This event captures when the user enters their mobile number during onboarding.

### MPIN Set
`mpin_set`
This event captures when the user sets their MPIN during onboarding.

### Name Entered
`name_entered`
This event captures when the user enters their name during onboarding.

### Notification Received
`notification_received`
This event captures when the user receives a notification from the app.

### Onboarding Completed
`onboarding_completed`
This event indicates that the user has completed the onboarding process.

### OTP Requested
`otp_requested`
This event captures when the user requests an OTP for verification.

### OTP Verified
`otp_verified`
This event signifies that the user has successfully verified their OTP.

### PAN Entered
`pan_entered`
This event captures when the user enters their PAN during onboarding.

### PAN Validation Completed
`pan_validation_completed`
This event indicates that the PAN validation process has been successfully completed.

### PAN Validation Initiated
`pan_validation_initiated`
This event captures when the PAN validation process is initiated.

### SIM Binding Completed
`sim_binding_completed`
This event indicates that the SIM binding process has been successfully completed.

### SIM Binding Initiated
`sim_binding_initiated`
This event captures when the SIM binding process is initiated.

### Transaction Reconciled
`transaction_reconciled`
This event indicates that a transaction has been successfully reconciled.

### vKYC Call Completed
`vkyc_call_completed`
This event indicates that the vKYC call has been successfully completed.

### vKYC Call Started
`vkyc_call_started`
This event captures when the vKYC call is initiated.

### vKYC Failed
`vkyc_failed`
This event indicates that the vKYC call has failed.

### vKYC Initiated
`vkyc_initiated`
This event captures when the vKYC process is initiated.
