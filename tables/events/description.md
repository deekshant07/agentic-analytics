# User Events Log

This table stores user interaction events within the Jupiter Money app, tracking user engagement and onboarding processes.

### Aadhaar Number Entered
`aadhaar_number_entered`
This event captures when a user inputs their Aadhaar number during the onboarding process.

### Aadhaar OTP Requested
`aadhaar_otp_requested`
This event indicates that the user has requested an OTP to verify their Aadhaar number.

### Aadhaar OTP Verified
`aadhaar_otp_verified`
This event signifies that the user has successfully verified their Aadhaar number using the OTP.

### App Installed
`app_install`
This event captures when the user installs the app on their device.

### App Opened
`app_opened`
This event captures when the user opens the app.

### Bureau Pull Completed
`bureau_pull_completed`
This event indicates that the bureau pull process has been completed successfully.

### Bureau Pull Initiated
`bureau_pull_initiated`
This event indicates that the bureau pull process has been initiated.

### Date of Birth Entered
`dob_entered`
This event captures when the user inputs their date of birth during onboarding.

### Email Entered
`email_entered`
This event captures when the user inputs their email address during onboarding.

### Home Screen Viewed
`home_screen_viewed`
This event indicates that the user has viewed the home screen of the app.

### Mobile Number Entered
`mobile_number_entered`
This event captures when the user inputs their mobile number during onboarding.

### MPIN Set
`mpin_set`
This event captures when the user sets their MPIN for the app.

### Name Entered
`name_entered`
This event captures when the user inputs their name during onboarding.

### Notification Received
`notification_received`
This event indicates that the user has received a notification from the app.

### Onboarding Completed
`onboarding_completed`
This event signifies that the user has completed the onboarding process.

### OTP Requested
`otp_requested`
This event indicates that the user has requested an OTP for verification.

### OTP Verified
`otp_verified`
This event signifies that the user has successfully verified the OTP.

### PAN Entered
`pan_entered`
This event captures when the user inputs their PAN during onboarding.

### PAN Validation Completed
`pan_validation_completed`
This event indicates that the PAN validation process has been completed successfully.

### PAN Validation Initiated
`pan_validation_initiated`
This event indicates that the PAN validation process has been initiated.

### SIM Binding Completed
`sim_binding_completed`
This event indicates that the SIM binding process has been completed successfully.

### SIM Binding Initiated
`sim_binding_initiated`
This event indicates that the SIM binding process has been initiated.

### Transaction Reconciled
`transaction_reconciled`
This event indicates that a transaction has been reconciled successfully.

### vKYC Call Completed
`vkyc_call_completed`
This event indicates that the vKYC call has been completed successfully.

### vKYC Call Started
`vkyc_call_started`
This event indicates that the vKYC call has been initiated.

### vKYC Failed
`vkyc_failed`
This event indicates that the vKYC call has failed.

### vKYC Initiated
`vkyc_initiated`
This event indicates that the vKYC process has been initiated.
